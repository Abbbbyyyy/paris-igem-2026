# Paris Field Notes · 巴黎 iGEM 旅行手册

中文、手机适配的静态交互旅行网站。无需账户、数据库、构建工具或地图API密钥。

## iPhone 直接使用

在线入口：https://abbbbyyyy.github.io/paris-igem-2026/

在 iPhone Safari 打开后，等待顶部显示“行程已可离线使用”，通过“共享 → 添加到主屏幕”保存。第一次访问需联网；之后文字行程可离线读取，地图底图、导航和实时交通仍需联网。此网站独立运行，不依赖个人电脑开机。备注只保存在当前浏览器；更换设备或浏览器时需要手动备份和恢复。

网站及仓库公开可访问，包含指南里的酒店与旅行日期；没有账户登录保护。

## iPhone 版（2026-11-07）

已沿用原有六日计划与预约状态，未修改行程事实。手机默认先显示时间线，底部可跳到地图和随身指南；日期栏可横滑并固定在顶部，表单字号和操作区域适配触摸屏。

### 随身离线文件

`Paris-iPhone.html` 为单文件版，另同步生成到上一级 iCloud Drive 的同名文件。iPhone 在“文件 → iCloud Drive”中找到它，先下载或选择“保留下载”（如该选项可用），然后预览。完整六日文字、地址和交通说明已写入 HTML；即使预览器不执行 JavaScript 也能阅读。系统预览中的脚本、锚点、外部链接行为由 iOS 决定，不能保证所有交互可用。完整交互请用 Safari 网页版。单文件版无需字体 CDN；地图底图和外部链接仍需联网。

### 同一 Wi-Fi 下立即预览

在 Mac 双击 `启动iPhone预览.command`，或在本目录运行：

```sh
HOST=0.0.0.0 PORT=4174 node server.cjs
```

iPhone 与 Mac 接入同一 Wi-Fi，在 Safari 打开终端显示的局域网地址。不要在手机输入 `localhost` 或 `127.0.0.1`。Mac 须保持开机，服务须保持运行；访客网络隔离、防火墙、VPN 可能阻断访问。仅共享网站文件，不提供 `.git`、测试输出或备注备份访问。

局域网 HTTP 适合即时预览；Safari 的离线缓存与设备定位需要 HTTPS 安全环境，局域网普通 HTTP 不具备这些能力。此地址离开家中网络后不可用。

### 外出使用完整交互版

本目录包含 Web App Manifest、主屏幕图标及 Service Worker。部署到自己的 HTTPS 静态网站后，在 iPhone Safari 打开，等待顶部显示“行程已可离线使用”，再通过“共享 → 添加到主屏幕”安装。开飞行模式后关闭重开，核对行程是否仍可读取。地图底图、实时交通、官网和导航需要网络；不预缓存 OSM 地图瓦片。已按用户要求公开部署到上方 GitHub Pages 地址。

### 维护与验证

修改源码后运行 `node build-iphone.cjs`，同步重建两份单文件版。Windows 修改者可使用同一脚本；不需要安装 npm 依赖。`output/iphone-check.cjs` 记录本次手机视口检查（本机 Playwright 和 Chrome）。已检查日期、搜索、地图按钮、可选安排、备注和状态持久化、JSON 恢复、ICS 巴黎时间转换、Service Worker 断网重开、320/375/390/430/844 宽度与桌面布局，以及禁用 JavaScript 的离线文件阅读。地图测试使用替代图片，不代表真实瓦片网络可达。没有连接实体 iPhone，未执行 iOS Safari / Quick Look 实机测试。

## 打开

可以直接双击 `index.html`（需要联网加载地图底图）。更完整的离线缓存和定位功能需要HTTPS或localhost：

```sh
node server.cjs
```

浏览器打开 http://127.0.0.1:4173 。此地址只在运行服务器的电脑上有效，手机远程访问需要部署。

## GitHub Pages 部署

1. 在自己的GitHub账户中新建仓库，如 `paris-igem-2026`。
2. 上传本目录的 `index.html`、`style.css`、`data.js`、`app.js`、`sw.js`、`vendor` 文件夹、README以及`.nojekyll`。入口必须在仓库根目录。
3. 仓库 Settings → Pages → Deploy from a branch → main → / (root) → Save。
4. 等部署完成，访问 `https://你的用户名.github.io/paris-igem-2026/`。在iPhone Safari可“共享→添加到主屏幕”。

本项目按用户要求发布到公开 GitHub Pages。仓库中含私人旅行日期、酒店和航班安排，公开前请审视隐私。不要上传护照、门票PDF、二维码、订单或备注备份。

## 功能

- 11月12–17日六天时间线，包含交通、换乘方向、预计耗时、地点、预约状态和官方链接。
- Leaflet交互地图，OpenStreetMap底图；日期切换、地点搜索、卡片定位、摄影点筛选、设备定位。
- 虚线只表达访问顺序，绝不是实际公共交通线路或步行路线；Google Maps路线按钮用于规划实际路线，Apple Maps打开地点。
- 行程完成、预约勾选和备注保存在localStorage；JSON导入/导出手动跨设备同步。
- 导出ICS日历，巴黎当地时间正确转换为UTC。可选项目明确标记，所有六天均导出。
- 打印当前日行程；首次联网经HTTP/HTTPS打开后缓存文字与本地资源。地图底图、实时交通、导航和官网需要网络；不批量下载OSM瓦片。
